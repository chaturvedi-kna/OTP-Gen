Request a Phone Number
GET

Get a temporary SMS number for SMS verification. If operator is omitted, maxPrice selects price-first auto mode; without maxPrice it selects best mode. Use a numeric operator to choose one operator; operator=cheap targets only the lowest-priced eligible operator; operator=auto tries eligible operators from lowest final price to highest; operator=best tries the highest-success-rate operator first.

Endpoint
GET
https://api.temporasms.com/stubs/handler_api.php?api_key=$api_key&action=getNumber&service=$service&country=$country&operator=$operator&providerIds=$providerIds
Parameters
Field	Type	Required	Description
api_key	String	Yes	Your API key.
action	String	Yes	API action to perform.
service	String	Yes	Service identifier, for example wa or go.
country	String	Yes	Country identifier, for example 22 or 21.
operator	String	No	Optional operator identifier, for example 1 or 2.
maxPrice	Integer	No	Maximum price you approve for the number.
providerIds	String	No	Optional public provider option IDs from getPricesV3, tried in the supplied order.
Automatic operator selection

The operator parameter is optional. Omitting it with maxPrice behaves like operator=auto; omitting both uses operator=best.

operator=auto
Lowest final price first; try the next operator if unavailable.
operator=cheap
Only the single lowest-priced eligible operator.
operator=best
Highest success-rate operator first; then the next if unavailable.
Response
Code / Key	Value / Description
ACCESS_NUMBER:3423423432:914738485900	Activation successful; returns order ID and phone number.
NO_NUMBERS	No description available.
Error Responses
Code	Description
BAD_ACTION	Invalid action requested.
BAD_SERVICE	Requested service is unavailable or invalid.
NO_BALANCE	Insufficient balance to complete the request.
BAD_OPERATOR	Invalid or unsupported operator specified.
BAD_COUNTRY	Invalid or unsupported country code.
WRONG_MAX_PRICE	The max price parameter is invalid.
BAD_KEY	Invalid or missing API key.
SERVICE_BANNED	Temporarily blocked due to excessive requests/cancellations.
USER_BANNED	Your account has been banned.
ERROR	A generic server error occurred.
TOO_MANY_REQUESTS	Rate limit exceeded. Please slow down your requests.
UNDER_DEVELOPMENT	This feature is under development. Please try later.
